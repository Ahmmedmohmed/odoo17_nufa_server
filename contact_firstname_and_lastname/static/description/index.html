Customer First name last name

This module enables you to maintain your customers or vendors records with their separate First and Last Names of Individual type contacts.

Description

Description

In the standard version of Odoo, there is no segregation of contact names into First Name and Last Name. This module has been specifically designed to meet the customer requirements to have separate fields for First Name and Last Name. Having the separate names, assists in extended searching and filtering of the contacts.

Standout Features

Standout Features

  • No Configuration is needed. Just download and install
  • Available on all forms: vendor, customer and contact
  • Supports extensive Searching and Filtering

Exploring the module: (How to)

Exploring the module: (How to)

  • Download and Install the app > Go to menu bar > Select Contacts
  • Select the Individual, Customer/Partner First name and Last name will appear in the field.
  • Customer complete name will be appeared on the contact card.
